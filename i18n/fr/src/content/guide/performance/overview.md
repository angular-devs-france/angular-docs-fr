Découvrez les différentes façons d'optimiser les performances de votre application grâce à différentes stratégies de rendu.
</docs-decorative-header>

L'une des priorités de tout développeur est de garantir que son application soit aussi performante que possible. Ces guides vous aident à suivre les bonnes pratiques pour construire des applications performantes en tirant parti de différentes stratégies de rendu.

| Types de guides                                       | Description                                                                                                                                                                             |
| :---------------------------------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Rendu serveur et hybride](/guide/ssr)                | Découvrez comment tirer parti du rendu des pages sur le serveur pour améliorer les temps de chargement.                                                                                 |
| [Hydratation](/guide/hydration)                       | Un processus qui améliore les performances de l'application en restaurant son état après le rendu côté serveur et en réutilisant autant que possible la structure DOM existante.        |
| [Hydratation incrémentale](/guide/incremental-hydration) | L'hydratation incrémentale est un type avancé d'hydratation qui peut laisser des sections de votre application déshydratées et déclencher progressivement leur hydratation au fur et à mesure des besoins. |
