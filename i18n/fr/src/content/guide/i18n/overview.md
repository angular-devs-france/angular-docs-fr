L'_internationalisation_, parfois désignée par i18n, est le processus de conception et de préparation de votre projet pour qu'il puisse être utilisé dans différentes locales à travers le monde.
La _localisation_ est le processus de construction de versions de votre projet pour différentes locales.
Le processus de localisation comprend les actions suivantes.

- Extraire le texte à traduire dans différentes langues
- Formater les données pour une locale spécifique

Une _locale_ identifie une région dans laquelle les gens parlent une langue ou une variante de langue particulière.
Les régions possibles incluent les pays et les régions géographiques.
Une locale détermine le formatage et l'analyse des éléments suivants.

- Les unités de mesure, notamment la date et l'heure, les nombres et les devises
- Les noms traduits, notamment les fuseaux horaires, les langues et les pays
