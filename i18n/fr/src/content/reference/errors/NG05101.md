# Aucun plugin de gestionnaire d'événements trouvé pour l'événement

Cette erreur se produit lorsqu'Angular tente de mettre en place un event listener pour un événement, mais qu'aucun des plugins de gestionnaire d'événements enregistrés ne reconnaît le nom de l'événement.

## Déboguer l'erreur {#debugging-the-error}

Le message d'erreur inclut le nom de l'événement non reconnu. L'erreur ne se produit que lorsqu'aucun plugin enregistré ne prend en charge l'événement, par exemple lorsqu'un `EventManager` est créé avec une liste de plugins personnalisée qui n'inclut pas `DomEventsPlugin`, comme dans des tests unitaires ou des configurations personnalisées.

Si le nom de l'événement est voulu et appartient à un plugin tiers (par exemple, un événement de geste Hammer.js), assurez-vous que le plugin est fourni via le jeton `EVENT_MANAGER_PLUGINS` :

```typescript
import {ApplicationConfig} from '@angular/core';
import {EVENT_MANAGER_PLUGINS} from '@angular/platform-browser';

export const appConfig: ApplicationConfig = {
  providers: [{provide: EVENT_MANAGER_PLUGINS, useClass: MyCustomPlugin, multi: true}],
};
```
