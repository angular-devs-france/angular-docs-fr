# Iterable differ manquant

`NgFor` n'a pas trouvé d'iterable differ pour la valeur transmise. Assurez-vous qu'il s'agit d'un itérable, comme un `Array`.

## Déboguer l'erreur {#debugging-the-error}

Lorsque vous utilisez ngFor dans un template, vous devez utiliser un type d'itérable, comme `Array` ou `Set`.
Si vous essayez d'itérer sur les clés d'un objet ou les entrées d'une `Map`, tournez-vous plutôt vers le [pipe KeyValue](/api/common/KeyValuePipe).
