# Binding non pris en charge sur un champ de formulaire

Un template lie, ou définit comme attribut statique, une propriété que les Signal Forms contrôlent déjà sur un élément via la directive `[formField]`.
L'état du champ est la source de vérité unique pour des propriétés comme `min`, `max`, `required`, `disabled` et `readonly`. Les indiquer dans le template entre en conflit avec la logique du schéma du champ.

Le message d'erreur nomme le binding. Il indique soit « Binding to '[min]' is not allowed... », soit « Setting the 'required' attribute is not allowed... ».

```angular-ts
import {Component, signal} from '@angular/core';
import {form, FormField} from '@angular/forms/signals';

@Component({
  selector: 'app-root',
  imports: [FormField],
  template: `
    <!-- NG8022: [min] and [max] are not allowed with [formField]. -->
    <input type="number" [formField]="f.age" [min]="18" [max]="99" />

    <!-- NG8022: the required attribute is not allowed with [formField]. -->
    <input type="text" [formField]="f.name" required />
  `,
})
export class App {
  f = form(signal({age: 20, name: ''}));
}
```

Il en va de même pour un [contrôle de formulaire personnalisé](guide/forms/signals/custom-controls) quand le template lie un input géré par le champ, comme `[max]` sur un contrôle qui déclare un input `max`.

Les propriétés qui ne peuvent pas être utilisées avec `[formField]` incluent :

- **Valeurs :** `value`, `checked` (gérées directement par le signal du modèle sous-jacent)
- **Règles de validation :** `required`, `min`, `max`, `minLength`, `maxLength`, `pattern` (ainsi que les attributs HTML natifs `minlength` et `maxlength`)
- **État interactif :** `disabled`, `readonly`, `hidden`
- **Statut et métadonnées du champ :** `name`, `dirty`, `touched`, `invalid`, `errors`, `pending`, `disabledReasons` (sur les contrôles personnalisés, `FormField` transmet automatiquement ces états au contrôle ; les lier manuellement entre donc en conflit avec le câblage automatique du framework)

Il existe quelques exceptions sur les éléments natifs :

- `min` et `max` sont autorisés sur les éléments `<input>` de type `date`, `time`, `month`, `week` et `datetime-local`. Sur ces types, les limites sont des chaînes de date ou d'heure comme `2026-01-01`, que les règles numériques `min()` et `max()` ne peuvent pas exprimer.
- `min` et `max` sont aussi autorisés quand le `type` est lié dynamiquement, car le compilateur ne peut pas savoir quel type a l'input.
- `value` est autorisé sur `<input type="radio">`, car il identifie alors l'option. La valeur du champ décide quel bouton radio est coché.

## Déboguer l'erreur {#debugging-the-error}

Retirez le binding du template, puis traitez la propriété selon sa catégorie :

- **Valeurs (`value`, `checked`) :** `[formField]` lie automatiquement l'élément au signal du modèle sous-jacent et les synchronise dans les deux sens. Pour initialiser ou modifier des valeurs, mettez à jour le signal du modèle passé à `form()`.
- **Règles de validation (`required`, `min`, `max`, `maxLength`, etc.) :** déclarez-les dans la fonction de schéma de `form()` à l'aide des [règles de validation](guide/forms/signals/validation) correspondantes.
- **État interactif (`disabled`, `readonly`, `hidden`) :** utilisez les règles de schéma `disabled()`, `readonly()` et `hidden()`, qui acceptent aussi une condition `when` facultative, pour qu'une règle puisse dépendre d'autres champs. Consultez la [logique de formulaire](guide/forms/signals/form-logic).
- **Statut et métadonnées du champ (`dirty`, `touched`, `errors`, etc.) :** aucun remplacement n'est nécessaire. `[formField]` les applique depuis l'état du champ, et vous pouvez les lire depuis le champ, par exemple `f.age().dirty()`.

L'exemple ci-dessus devient alors :

```angular-ts
import {Component, signal} from '@angular/core';
import {disabled, form, FormField, max, maxLength, min, required} from '@angular/forms/signals';

@Component({
  selector: 'app-root',
  imports: [FormField],
  template: `
    <input type="number" [formField]="f.age" />
    <input type="text" [formField]="f.name" />
  `,
})
export class App {
  f = form(signal({age: 20, name: ''}), (p) => {
    min(p.age, 18);
    max(p.age, 99);
    required(p.name);
    maxLength(p.name, 20);
    disabled(p.name, {when: ({valueOf}) => valueOf(p.age) < 18});
  });
}
```
