# Un input obligatoire est lu avant qu'une valeur ne soit définie.

Un input obligatoire a été lu alors qu'aucune valeur ne lui était liée.

Cela peut se produire lorsqu'un input obligatoire est lu trop tôt dans votre directive ou votre composant.
C'est souvent le cas lorsque l'input est lu pendant la construction de la classe.

Les inputs sont garantis disponibles dans le lifecycle hook `ngOnInit` et après.

## Corriger l'erreur {#fixing-the-error}

Lisez l'input obligatoire dans des contextes réactifs.
Par exemple, dans le template lui-même, dans un `computed` ou dans un effect.

Vous pouvez aussi lire l'input dans le lifecycle hook `ngOnInit`, ou plus tard.
