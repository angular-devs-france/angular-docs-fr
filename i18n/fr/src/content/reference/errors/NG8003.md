# Cible de référence manquante

<docs-video src="https://www.youtube.com/embed/fUSAg4kp2WQ"/>

Angular ne trouve pas de directive ayant le nom d'export `{{ PLACEHOLDER }}`.
C'est fréquent lorsqu'il manque un import ou un [`exportAs`](api/core/Directive#exportAs) sur une directive.

HELPFUL: C'est l'équivalent, côté compilateur, d'une erreur d'exécution courante : [NG0301 : Export introuvable](errors/NG0301).

## Déboguer l'erreur {#debugging-the-error}

Utilisez le nom (sous forme de chaîne) de l'export introuvable pour remonter jusqu'aux templates ou aux modules qui utilisent cet export.

Assurez-vous que toutes les dépendances sont correctement importées et déclarées dans vos modules.
Par exemple, si l'export introuvable est `ngForm`, vous devez importer `FormsModule` et le déclarer dans votre liste d'imports dans `*.module.ts` pour résoudre l'erreur d'export manquant.

```ts

import { FormsModule } from '@angular/forms';

@NgModule({
…
imports: [
FormsModule,
…

```

Si vous avez récemment ajouté un import, vous devrez redémarrer votre serveur pour voir ces modifications.
