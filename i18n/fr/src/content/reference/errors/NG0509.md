# Nœud manquant sur le chemin lors de l'hydratation

Les builds de production affichent cette erreur quand Angular ne trouve pas un nœud pendant l'hydratation. Angular suit un chemin qu'il a enregistré pendant le rendu côté serveur, mais un nœud de ce chemin est manquant. Cela signifie que le DOM dans le navigateur est différent du HTML venant du serveur.

Les builds de production n'incluent pas les messages d'erreur, vous ne voyez donc que le code `NG0509`. Les builds de développement affichent le même problème sous la forme de l'[erreur NG0502](errors/NG0502), et le message vous indique le nœud host et le chemin.

## Causes courantes {#common-causes}

Les causes sont les mêmes que pour l'[erreur NG0500](errors/NG0500). Vérifiez aussi les modifications venant de l'extérieur de votre application, par exemple d'une fonctionnalité de CDN ou d'une extension de navigateur. Lisez [CDN et extensions de navigateur](guide/hydration#cdns-and-browser-extensions) dans le guide sur l'hydratation.

## Déboguer l'erreur {#debugging-the-error}

- Si vous pouvez reproduire le problème dans un build de développement, utilisez ce build. Le message `NG0502` vous indique le nœud host et le chemin.
- Comparez le HTML de la production avec le HTML de votre serveur local. Si vous voyez des éléments `__cf_email__`, ou s'il manque des nœuds de commentaire, une fonctionnalité de CDN en est probablement la cause.
- Ouvrez la page dans un profil de navigateur sans extensions. Si l'erreur disparaît, une extension modifie la page.
