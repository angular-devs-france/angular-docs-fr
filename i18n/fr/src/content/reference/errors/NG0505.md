# Aucune information d'hydratation dans la réponse du serveur

Cette erreur se produit lorsque l'hydratation est activée sur le client, mais que la réponse du serveur
ne contient pas les informations sérialisées spécifiques à l'application sur lesquelles
repose la logique d'hydratation.

Cela peut arriver lorsque la fonction `provideClientHydration()` est incluse dans la partie client
de la configuration de l'application, mais absente de la partie serveur de la configuration.

Dans les applications qui suivent la structure de projet par défaut (générée par `ng new`),
l'appel à `provideClientHydration()` est ajouté soit dans le tableau `providers` du
`AppModule` principal (qui est importé dans le module serveur), soit dans un ensemble de
providers inclus à la fois dans la configuration client et dans la configuration serveur.

Si vous avez une configuration personnalisée où les configurations client et serveur sont indépendantes
et ne partagent pas d'ensemble commun de providers, assurez-vous que `provideClientHydration()`
est aussi inclus dans l'ensemble de providers utilisé pour le bootstrap de l'application sur le serveur.

Vous trouverez plus d'informations sur l'hydratation dans [ce guide](guide/hydration).

## Déboguer l'erreur {#debugging-the-error}

Vérifiez que l'appel à `provideClientHydration()` est inclus dans un ensemble de providers
utilisé pour le bootstrap de l'application sur le serveur.
