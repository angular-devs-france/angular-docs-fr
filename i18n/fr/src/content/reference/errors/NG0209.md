# Multi provider invalide

Le runtime d'Angular lève cette erreur lorsqu'il injecte un jeton destiné à être utilisé avec `multi: true` mais
qu'il trouve une valeur qui n'est pas un tableau. Par exemple, `ENVIRONMENT_INITIALIZER` doit être fourni
sous la forme `{provide: ENVIRONMENT_INITIALIZER, multi: true, useValue: () => {...}}`.
