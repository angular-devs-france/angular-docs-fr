# Élément racine introuvable

Les composants de bootstrap sont définis dans la propriété `bootstrap` d'un décorateur `@NgModule` ou comme premier paramètre de `bootstrapApplication` pour les composants standalone.

Cette erreur se produit lorsqu'Angular tente de lancer le bootstrap de l'un de ces composants mais ne trouve pas le nœud correspondant dans le DOM.

## Déboguer l'erreur {#debugging-the-error}

Ce problème se produit lorsque le selector ne correspond pas à la balise

```typescript
@Component({
  selector: 'my-app',
  ...
})
export class App {}
```

<!-- prettier-ignore -->
```html
<html>
  <app-root></app-root> <!-- Doesn't match the selector -->
</html>
```

Remplacez la balise par la bonne :

<!-- prettier-ignore -->
```html
<html>
  <my-app></my-app> <!-- OK -->
</html>
```
