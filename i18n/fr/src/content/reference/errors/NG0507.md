# Le contenu HTML a été modifié après le rendu côté serveur

Angular lève cette erreur lorsqu'il détecte que le contenu généré par le rendu côté serveur (SSR) a été modifié après le rendu. Le processus d'hydratation exige que le contenu reste intact après le SSR, y compris les espaces blancs et les nœuds de commentaire. Ces espaces blancs et nœuds de commentaire doivent être conservés dans le HTML généré par le processus SSR. Pour en savoir plus, consultez le guide de l'hydratation.

## Déboguer l'erreur {#debugging-the-error}

Cela se produit généralement dans les cas suivants :

Certains fournisseurs de CDN proposent une fonctionnalité intégrée qui supprime les espaces blancs et les nœuds de commentaire du HTML à des fins d'optimisation. Vérifiez si une telle option existe dans la configuration de votre CDN et désactivez-la.
Si vous appliquez un post-traitement personnalisé au HTML généré par le SSR (comme étape de build), assurez-vous que ce processus ne supprime pas les espaces blancs ni les nœuds de commentaire.
