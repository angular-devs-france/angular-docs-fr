# Hydratation avec une instance de Zone.js non prise en charge

Cet avertissement signifie que l'hydratation a été activée pour une application configurée pour utiliser une version de Zone.js non prise en charge : soit une version personnalisée, soit une version « noop » (voir plus d'informations [ici](api/core/BootstrapOptions#ngZone)).

L'hydratation s'appuie sur un signal de Zone.js indiquant que l'application devient stable, afin qu'Angular puisse lancer le processus de sérialisation sur le serveur ou le nettoyage post-hydratation sur le client (pour supprimer les nœuds DOM restés non réclamés).

Fournir une implémentation de Zone.js personnalisée ou « noop » peut modifier le moment où l'événement « stable » se produit, et donc déclencher la sérialisation ou le nettoyage trop tôt ou trop tard. Cette configuration n'est pas encore entièrement prise en charge.

Si vous utilisez une implémentation personnalisée de Zone.js, assurez-vous que l'événement « onStable » est émis au bon moment et n'entraîne pas de comportement incorrect de l'application avec l'hydratation.

Vous trouverez plus d'informations sur l'hydratation dans le [guide de l'hydratation](guide/hydration).
