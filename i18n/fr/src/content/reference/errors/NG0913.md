# Avertissements de performances à l'exécution

### Images surdimensionnées {#oversized-images}

Lorsque des images sont chargées, la **taille intrinsèque** du fichier téléchargé est comparée à la taille réelle de l'image sur la page. La taille réelle est calculée à partir de la **taille de rendu** de l'image une fois le CSS appliqué, multipliée par le [ratio de pixels de l'appareil](https://web.dev/codelab-density-descriptors/#pixel-density). Si l'image téléchargée est beaucoup plus grande (plus de 1200px de trop dans l'une ou l'autre dimension), cet avertissement est déclenché. Télécharger des images surdimensionnées peut ralentir le chargement de la page et avoir un effet négatif sur les [Core Web Vitals](https://web.dev/vitals/).

### Élément LCP chargé en lazy loading {#lazy-loaded-lcp-element}

Le plus grand élément de contenu d'une page pendant le chargement est considéré comme l'« élément LCP », qui se rapporte au [Largest Contentful Paint](https://web.dev/lcp/), l'une des Core Web Vitals. Charger un élément LCP en lazy loading a un effet très négatif sur les performances de la page. Avec cette stratégie, le navigateur doit terminer les calculs de mise en page pour déterminer si l'élément se trouve dans le viewport avant de commencer à télécharger l'image. Par conséquent, un avertissement est déclenché lorsqu'Angular détecte que l'élément LCP a reçu l'attribut `loading="lazy"`.

### Déboguer l'erreur {#debugging-the-error}

Utilisez l'URL de l'image fournie dans l'avertissement de la console pour trouver l'élément `<img>` concerné.

### Corriger les images surdimensionnées {#ways-to-fix-oversized-images}

- Utilisez une image source plus petite
- Ajoutez un [`srcset`](https://web.dev/learn/design/responsive-images/#responsive-images-with-srcset) si plusieurs tailles sont nécessaires pour différentes mises en page.
- Passez à la directive d'image intégrée d'Angular ([`NgOptimizedImage`](/api/common/NgOptimizedImage)), qui génère [les srcsets automatiquement](/guide/image-optimization#request-images-at-the-correct-size-with-automatic-srcset).

### Corriger un élément LCP chargé en lazy loading {#ways-to-fix-lazy-loaded-lcp-element}

- Remplacez la valeur de l'attribut `loading` par une autre, comme `"eager"`.
- Passez à la directive d'image intégrée d'Angular ([`NgOptimizedImage`](/api/common/NgOptimizedImage)), qui permet de facilement [rendre prioritaires les images LCP](/guide/image-optimization#mark-images-as-priority).

### Désactiver les avertissements de performances des images {#disabling-image-performance-warnings}

Les deux avertissements peuvent être désactivés individuellement, pour tout le site, à l'aide d'un provider à la racine de votre application :

```typescript
providers: [
  {
    provide: IMAGE_CONFIG,
    useValue: {
      disableImageSizeWarning: true,
      disableImageLazyLoadWarning: true
    }
  },
],
```
