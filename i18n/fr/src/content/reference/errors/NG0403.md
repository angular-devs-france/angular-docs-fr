# Le NgModule utilisé pour le bootstrap n'indique pas quel composant initialiser

Cette erreur signifie qu'il manque à un NgModule utilisé pour le bootstrap d'une application des informations essentielles dont Angular a besoin pour poursuivre le processus de bootstrap.

L'erreur se produit lorsque la propriété `bootstrap` du NgModule est absente (ou est un tableau vide) dans l'annotation `@NgModule` et qu'aucun lifecycle hook `ngDoBootstrap` n'est défini sur la classe de ce NgModule.

Vous trouverez plus d'informations sur le processus de bootstrap dans [ce guide](guide/ngmodules/overview).

Les exemples suivants déclenchent l'erreur.

```typescript
@NgModule({
  declarations: [App],
  imports: [BrowserModule, AppRoutingModule],
  providers: [],
})
export class AppModule {}

// The `AppModule` is used for bootstrapping, but the `@NgModule.bootstrap` field is missing.
platformBrowser().bootstrapModule(AppModule);
```

```typescript
@NgModule({
  declarations: [App],
  imports: [BrowserModule, AppRoutingModule],
  providers: [],
  bootstrap: [],
})
export class AppModule {}

// The `AppModule` is used for bootstrapping, but the `@NgModule.bootstrap` field contains an empty array.
platformBrowser().bootstrapModule(AppModule);
```

## Déboguer l'erreur {#debugging-the-error}

Assurez-vous que le NgModule utilisé pour le bootstrap est correctement configuré :

- soit la propriété `bootstrap` existe (et contient un tableau non vide) dans l'annotation `@NgModule`
- soit la méthode `ngDoBootstrap` existe sur la classe du NgModule
