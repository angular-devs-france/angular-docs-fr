# Jeton manquant

Il n'existe aucun jeton d'injection pour un paramètre de constructeur à la compilation. Les [InjectionTokens](api/core/InjectionToken) sont des jetons utilisables dans un provider de l'injection de dépendances.

## Déboguer l'erreur {#debugging-the-error}

Examinez le paramètre qui lève l'erreur, ainsi que toutes les utilisations de la classe.
Cette erreur est souvent levée lorsqu'un constructeur définit des paramètres de types primitifs comme `string`, `number`, `boolean` et `Object`.

Utilisez la méthode `@Injectable` ou le décorateur `@Inject` de `@angular/core` pour vous assurer que le type que vous injectez est réifié \(qu'il a une représentation à l'exécution\). Veillez à ajouter un provider à ce décorateur afin de ne pas lever l'erreur [NG0201 : Aucun provider trouvé](errors/NG0201).
