# Texte manquant lors de l'hydratation

Cette erreur est similaire à l'[erreur NG0500](errors/NG0500), mais elle signifie que le processus d'hydratation d'Angular attendait un nœud texte à un endroit précis du DOM et n'y a rien trouvé. Consultez la page de l'[erreur NG0500](errors/NG0500) pour les causes liées à la manipulation directe du DOM.

## Une cause fréquente : le HTML du serveur a changé avant l'hydratation {#a-common-cause-the-server-html-changed-before-hydration}

L'hydratation réutilise les nœuds texte produits par le rendu côté serveur. Si quelque chose supprime ou fusionne ces nœuds texte avant que le navigateur n'exécute l'application, le nœud qu'Angular cherche a disparu.

Les sources courantes sont un minifieur HTML, un proxy ou un CDN qui réécrit la réponse, une extension de navigateur, ou du code applicatif qui écrit du texte avec `innerHTML` en dehors d'Angular.

## Déboguer l'erreur {#debugging-the-error}

Consultez l'[erreur NG0500](errors/NG0500) pour des conseils de débogage des causes liées à la manipulation directe du DOM.

Comparez le HTML envoyé par le serveur avec le HTML reçu par le navigateur. Utilisez le code source de la page plutôt que l'inspecteur d'éléments, car l'inspecteur montre le DOM après que l'hydratation a déjà eu lieu. Si le texte est présent dans la réponse du serveur mais absent dans le navigateur, cherchez un outil intermédiaire qui réécrit le HTML.

Si vous ne contrôlez pas le HTML d'un composant, vous pouvez, en dernier recours, ajouter l'attribut `ngSkipHydration` à son nœud host. Cela désactive l'hydratation pour ce composant et ses enfants, et doit être considéré comme un bug à corriger.
