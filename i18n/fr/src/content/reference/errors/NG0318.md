# Valeur invalide pour un property binding de style

Angular a détecté une valeur d'un type non pris en charge dans un property binding de style. Cela peut se produire dans
un binding individuel comme `[style.width]` ou dans une propriété d'une map `[style]`.

Les valeurs de propriétés de style acceptent les chaînes, les nombres, les objets `SafeValue` de style, `null` et `undefined`.
Les autres valeurs, y compris les objets `SafeValue` créés pour un contexte de sécurité autre que le style, produisent cet
avertissement en mode développement.

Par exemple, le binding suivant transmet un booléen au lieu d'une valeur CSS :

```angular-html
<div [style.display]="isVisible"></div>
```

## Déboguer l'erreur {#debugging-the-error}

Utilisez le nom de la propriété et la valeur indiqués dans le message d'erreur pour localiser le binding. Convertissez la valeur en
chaîne CSS ou en nombre valide, ou utilisez `null` ou `undefined` pour supprimer le style.

Lorsque vous utilisez un suffixe d'unité comme `[style.width.px]`, liez la partie numérique de la valeur :

```angular-html
<div [style.width.px]="width"></div>
```

Ne transmettez pas de `SafeValue` créée pour un autre contexte de sécurité, comme du HTML de confiance, à un property binding
de style.
