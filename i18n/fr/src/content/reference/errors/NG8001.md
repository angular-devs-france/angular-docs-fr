# Élément invalide

Un ou plusieurs éléments ne peuvent pas être résolus pendant la compilation, car l'élément n'est pas défini par la spécification HTML, ou aucun composant ni aucune directive n'a de selector d'élément correspondant.

HELPFUL: C'est l'équivalent, côté compilateur, d'une erreur d'exécution courante : `NG0304: '${tagName}' is not a known element: ...`.

## Déboguer l'erreur {#debugging-the-error}

Utilisez le nom de l'élément indiqué dans l'erreur pour trouver le ou les fichiers où l'élément est utilisé.

Vérifiez que le nom et le selector sont corrects.

Assurez-vous que le composant est correctement importé dans votre NgModule ou votre composant standalone, en vérifiant sa présence dans le champ `imports`. Si le composant est déclaré dans un NgModule (c'est-à-dire qu'il n'est pas standalone), assurez-vous qu'il en est correctement exporté, en vérifiant sa présence dans le champ `exports`.

Si vous utilisez des custom elements ou des web components, veillez à ajouter [`CUSTOM_ELEMENTS_SCHEMA`](api/core/CUSTOM_ELEMENTS_SCHEMA) au module de l'application.

Si cela ne résout pas l'erreur, vérifiez si les libraries importées ont récemment modifié les exports et les propriétés que vous utilisez, puis redémarrez votre serveur.
