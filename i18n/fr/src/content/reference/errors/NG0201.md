# Aucun provider trouvé

<docs-video src="https://www.youtube.com/embed/lAlOryf1-WU"/>

Vous voyez cette erreur lorsque vous essayez d'injecter un service sans avoir déclaré de provider correspondant. Un provider est une correspondance qui fournit une valeur que vous pouvez injecter dans le constructeur d'une classe de votre application.

Pour en savoir plus sur les providers, consultez notre [guide de l'injection de dépendances](guide/di).

## Déboguer l'erreur {#debugging-the-error}

Remontez à partir de l'objet pour lequel l'erreur indique qu'un provider est manquant : `No provider for <token> found`. Cette erreur est souvent levée dans des services qui requièrent des providers inexistants.

Pour corriger l'erreur, assurez-vous que votre service est enregistré dans la liste des providers d'un `NgModule` ou qu'il porte le décorateur `@Service` en tête.

La solution la plus courante consiste à ajouter un provider dans `@Service`

```ts
@Service()
```
