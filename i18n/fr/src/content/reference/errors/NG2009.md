# Selector Shadow DOM invalide

Le selector d'un composant utilisant `ViewEncapsulation.ShadowDom` ne respecte pas les exigences relatives aux noms de balise des custom elements.

Pour qu'un nom de balise soit considéré comme un nom de custom element valide, il doit :

- Être en minuscules.
- Contenir un tiret.
- Commencer par une lettre \(a-z\).

## Déboguer l'erreur {#debugging-the-error}

Renommez le selector de votre composant pour qu'il respecte ces exigences.

**Avant :**

```ts
@Component({
  selector: 'comp',
  encapsulation: ViewEncapsulation.ShadowDom
…
})

```

**Après :**

```ts
@Component({
  selector: 'app-comp',
  encapsulation: ViewEncapsulation.ShadowDom
…
})
```
