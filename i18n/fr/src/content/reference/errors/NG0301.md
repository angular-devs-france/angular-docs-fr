# Export introuvable

<docs-video src="https://www.youtube.com/embed/fUSAg4kp2WQ"/>

Angular ne trouve pas de directive avec le nom d'export `{{ PLACEHOLDER }}`. Le nom d'export est spécifié dans la propriété `exportAs` du décorateur de la directive. Cela arrive souvent lorsque vous utilisez FormsModule ou des modules Material dans des templates et que vous avez oublié d'importer les modules correspondants.

HELPFUL: C'est l'équivalent à l'exécution d'une erreur de compilation courante, [NG8003: No directive found with export](errors/NG8003).

## Déboguer l'erreur {#debugging-the-error}

Utilisez le nom d'export pour retrouver les templates ou les modules qui utilisent cet export.

Assurez-vous que toutes les dépendances sont correctement importées et déclarées dans vos NgModules. Par exemple, si l'export introuvable est `ngForm`, il faut importer `FormsModule` et le déclarer dans la liste des imports de `*.module.ts` pour résoudre l'erreur.

```ts

import { FormsModule } from '@angular/forms';

@NgModule({
…
imports: [
FormsModule,
…

```

Si vous avez récemment ajouté un import, vous devrez peut-être redémarrer votre serveur pour voir ces changements.
