# Comportement de @defer quand le HMR est activé

Le Hot Module Replacement (HMR) est une technique utilisée par les serveurs de développement pour éviter de recharger toute la page lorsque seule une partie de l'application est modifiée.

Lorsque le HMR est activé dans Angular, toutes les dépendances des blocs `@defer` sont chargées
immédiatement, au lieu d'attendre les conditions de déclenchement configurées (aussi bien pour les déclencheurs côté client que pour ceux de l'hydratation incrémentale). C'est nécessaire
au bon fonctionnement du HMR, qui remplace les composants d'une application à l'exécution
sans avoir à recharger toute la page. Remarque : le rendu effectif des blocs defer
respecte les conditions de déclenchement en mode HMR.

Si vous voulez tester le comportement des blocs `@defer` en mode développement et vous assurer que
les dépendances nécessaires sont chargées lorsqu'une condition de déclenchement est remplie, vous pouvez
désactiver le mode HMR comme décrit dans [`ce document`](/tools/cli/build-system-migration#hot-module-replacement).
