# Pipe introuvable

<docs-video src="https://www.youtube.com/embed/maI2u6Sxk9M"/>

Angular ne trouve pas de pipe portant ce nom.

Le [pipe](guide/templates/pipes) référencé dans le template n'a pas été nommé ou déclaré correctement.

Pour utiliser le pipe :

- Assurez-vous que le nom utilisé dans le template correspond au nom défini dans le décorateur du pipe.
- Ajoutez le pipe au tableau `imports` de votre composant ou, si le pipe définit `standalone: false`, ajoutez le `NgModule` auquel le pipe appartient.

## Déboguer l'erreur {#debugging-the-error}

Utilisez le nom du pipe pour retrouver où le pipe est déclaré et utilisé.

Pour résoudre cette erreur :

- Si le pipe est local au `NgModule`, donnez-lui un nom unique dans le décorateur du pipe et déclarez-le dans le `NgModule`.
- Si le pipe est standalone ou déclaré dans un autre `NgModule`, ajoutez-le au champ `imports` du composant standalone ou du `NgModule` courant.

Si vous avez récemment ajouté un import ou une déclaration, vous devrez peut-être redémarrer votre serveur pour voir ces changements.
