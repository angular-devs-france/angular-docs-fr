# Référence de la CLI

| Commande                           | Alias      | Description                                                                                               |
| :--------------------------------- | :--------- | :-------------------------------------------------------------------------------------------------------- |
| [`add`](cli/add)                   |            | Ajoute la prise en charge d'une library externe à votre projet.                                           |
| [`analytics`](cli/analytics)       |            | Configure la collecte des métriques d'utilisation de l'Angular CLI.                                       |
| [`build`](cli/build)               | `b`        | Compile une application ou une library Angular dans un répertoire de sortie nommé dist/ au chemin de sortie indiqué. |
| [`cache`](cli/cache)               |            | Configure le cache disque persistant et récupère les statistiques du cache.                               |
| [`completion`](cli/completion)     |            | Configure l'autocomplétion de l'Angular CLI pour votre terminal.                                          |
| [`config`](cli/config)             |            | Récupère ou définit des valeurs de configuration Angular dans le fichier angular.json du workspace.       |
| [`deploy`](cli/deploy)             |            | Invoque le builder de déploiement pour un projet donné ou pour le projet par défaut du workspace.         |
| [`e2e`](cli/e2e)                   | `e`        | Compile et sert une application Angular, puis exécute les tests de bout en bout.                          |
| [`extract-i18n`](cli/extract-i18n) |            | Extrait les messages i18n du code source.                                                                 |
| [`generate`](cli/generate)         | `g`        | Génère et/ou modifie des fichiers à partir d'un schematic.                                                |
| [`lint`](cli/lint)                 |            | Exécute les outils de lint sur le code de l'application Angular dans un dossier de projet donné.          |
| [`new`](cli/new)                   | `n`        | Crée un nouveau workspace Angular.                                                                        |
| [`run`](cli/run)                   |            | Exécute une cible Architect avec une configuration de builder personnalisée facultative définie dans votre projet. |
| [`serve`](cli/serve)               | `s`, `dev` | Compile et sert votre application, en la recompilant à chaque modification de fichier.                    |
| [`test`](cli/test)                 | `t`        | Exécute les tests unitaires d'un projet.                                                                  |
| [`update`](cli/update)             |            | Met à jour votre workspace et ses dépendances. Consultez le [guide de mise à jour](/update-guide).        |
| [`version`](cli/version)           | `v`        | Affiche la version de l'Angular CLI.                                                                      |
