# Une propriété CSS numérique requiert une unité

Ce diagnostic détecte les cas où une valeur numérique est liée à une propriété CSS de longueur qui requiert une unité CSS pour avoir un effet.

```angular-html
<!-- Binding a bare number – has no visual effect -->
<div [style.width]="500"></div>

<!-- Binding a numeric string – also has no effect -->
<div [style.padding]="'20'"></div>
```

## Quel est le problème ? {#whats-wrong-with-that}

Les propriétés CSS de longueur comme `width`, `height`, `margin`, `padding`, `font-size` et bien d'autres requièrent une unité (par exemple `px`, `em`, `%`, `rem`) pour prendre effet. Lier un simple nombre comme `500` définit la propriété à la chaîne `"500"`, que les navigateurs considèrent comme une valeur invalide et ignorent silencieusement. L'élément est rendu comme si le style n'avait jamais été appliqué.

## Que faire à la place ? {#what-should-i-do-instead}

Il existe deux façons idiomatiques de lier une valeur de longueur avec une unité dans les templates Angular.

### Utiliser le raccourci de suffixe d'unité {#use-the-unit-suffix-shorthand}

Ajoutez l'unité souhaitée directement au nom du binding avec la syntaxe de suffixe `.unit` :

```angular-html
<div [style.width.px]="500"></div>
<div [style.padding.rem]="1.5"></div>
<div [style.margin-top.%]="10"></div>
```

### Lier une chaîne qui inclut déjà l'unité {#bind-a-string-that-already-includes-the-unit}

Si vous devez composer la valeur dynamiquement, liez plutôt une chaîne de valeur CSS complète :

```angular-html
<div [style.width]="'500px'"></div>
<div [style.padding]="myPadding + 'px'"></div>
```

## Prérequis de configuration {#configuration-requirements}

[`strictTemplates`](tools/cli/template-typecheck#strict-mode) doit être activé pour qu'un diagnostic
étendu soit émis.
`numericCssPropertyRequiresUnit` n'a pas d'autre prérequis que `strictTemplates`.

## Et si je ne peux pas l'éviter ? {#what-if-i-cant-avoid-this}

Ce diagnostic peut être désactivé en modifiant le fichier `tsconfig.json` du projet :

```json
{
  "angularCompilerOptions": {
    "extendedDiagnostics": {
      "checks": {
        "numericCssPropertyRequiresUnit": "suppress"
      }
    }
  }
}
```

Consultez la [configuration des diagnostics étendus](extended-diagnostics#configuration) pour en savoir plus.
