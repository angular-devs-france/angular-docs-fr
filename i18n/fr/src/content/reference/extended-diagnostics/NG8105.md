# Mot-clé `let` manquant dans une expression `*ngFor`

Ce diagnostic est émis lorsqu'il manque le mot-clé `let` dans une expression utilisée dans `*ngFor`.

```angular-ts
import {Component} from '@angular/core';

@Component({
  // The `let` keyword is missing in the `*ngFor` expression.
  template: `<div *ngFor="item of items">{{ item }}</div>`,
})
class MyComponent {
  items = [1, 2, 3];
}
```

## Quel est le problème ? {#whats-wrong-with-that}

Un `let` manquant révèle une erreur de syntaxe dans la chaîne `*ngFor`. Cela signifie aussi que `item` ne sera pas correctement mis dans la portée et que `{{ item }}` ne sera pas résolu correctement.

## Que faire à la place ? {#what-should-i-do-instead}

Ajoutez le mot-clé `let` manquant.

```angular-ts
import {Component} from '@angular/core';

@Component({
  // The `let` keyword is now present in the `*ngFor` expression,
  // no diagnostic messages are emitted in this case.
  template: `<div *ngFor="let item of items">{{ item }}</div>`,
})
class MyComponent {
  items = [1, 2, 3];
}
```

## Prérequis de configuration {#configuration-requirements}

[`strictTemplates`](tools/cli/template-typecheck#strict-mode) doit être activé pour qu'un diagnostic étendu soit émis.
`missingNgForOfLet` n'a pas d'autre prérequis que `strictTemplates`.

## Et si je ne peux pas l'éviter ? {#what-if-i-cant-avoid-this}

Ce diagnostic peut être désactivé en modifiant le fichier `tsconfig.json` du projet :

```json
{
  "angularCompilerOptions": {
    "extendedDiagnostics": {
      "checks": {
        "missingNgForOfLet": "suppress"
      }
    }
  }
}
```

Consultez la [configuration des diagnostics étendus](extended-diagnostics#configuration) pour en savoir plus.
