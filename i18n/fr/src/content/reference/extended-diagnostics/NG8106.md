# Suffixe non pris en charge

Ce diagnostic détecte l'utilisation des suffixes `.px`, `.%` et `.em` avec un attribute
binding.

```html
<img [attr.width.px]="5" />
```

## Quel est le problème ? {#whats-wrong-with-that}

Ces suffixes ne sont disponibles que pour les style bindings. Ils n'ont aucun sens dans un binding vers un attribut.

## Que faire à la place ? {#what-should-i-do-instead}

Au lieu d'utiliser les suffixes `.px`, `.%` ou `.em`, qui ne sont pris en charge que dans les style bindings,
déplacez l'unité dans la valeur affectée par le binding.

```html
<img [attr.width]="'5px'" />
```

## Prérequis de configuration {#configuration-requirements}

[`strictTemplates`](tools/cli/template-typecheck#strict-mode) doit être activé pour qu'un diagnostic étendu soit émis.
`suffixNotSupported` n'a pas d'autre prérequis que `strictTemplates`.

## Et si je ne peux pas l'éviter ? {#what-if-i-cant-avoid-this}

Ce diagnostic peut être désactivé en modifiant le fichier `tsconfig.json` du projet :

```json
{
  "angularCompilerOptions": {
    "extendedDiagnostics": {
      "checks": {
        "suffixNotSupported": "suppress"
      }
    }
  }
}
```

Consultez la [configuration des diagnostics étendus](extended-diagnostics#configuration) pour en savoir plus.
