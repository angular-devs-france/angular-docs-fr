# Les fonctions doivent être appelées dans les interpolations de texte.

Ce diagnostic détecte les fonctions non appelées dans les interpolations de texte.

```angular-ts
import {Component} from '@angular/core';

@Component({
  template: `{{ getValue }}`,
})
class MyComponent {
  getValue() {
    return 'value';
  }
}
```

## Quel est le problème ? {#whats-wrong-with-that}

Les fonctions utilisées dans une interpolation de texte doivent être appelées pour renvoyer une valeur.
Si la fonction n'est pas appelée, elle ne renverra aucune valeur et l'interpolation ne fonctionnera pas comme prévu.

## Que faire à la place ? {#what-should-i-do-instead}

Veillez à appeler la fonction lorsque vous l'utilisez dans une interpolation de texte, afin qu'elle renvoie la valeur.

```angular-ts
import {Component} from '@angular/core';

@Component({
  template: `{{ getValue() }}`,
})
class MyComponent {
  getValue() {
    return 'value';
  }
}
```

## Prérequis de configuration {#configuration-requirements}

[`strictTemplates`](/tools/cli/template-typecheck#strict-mode) doit être activé pour qu'un diagnostic étendu soit émis.
`uninvokedFunctionInTextInterpolation` n'a pas d'autre prérequis que `strictTemplates`.

## Et si je ne peux pas l'éviter ? {#what-if-i-cant-avoid-this}

Ce diagnostic peut être désactivé en modifiant le fichier `tsconfig.json` du projet :

```json
{
  "angularCompilerOptions": {
    "extendedDiagnostics": {
      "checks": {
        "uninvokedFunctionInTextInterpolation": "suppress"
      }
    }
  }
}
```

Consultez la [configuration des diagnostics étendus](/extended-diagnostics#configuration) pour en savoir plus.
