Ce tutoriel interactif vous enseigne les fondamentaux des signals Angular et comment les utiliser pour construire des applications réactives.

## Comment utiliser ce tutoriel {#how-to-use-this-tutorial}

Ce tutoriel suppose que vous maîtrisez les concepts de base d'Angular. Si vous découvrez Angular, lisez notre [guide des Fondamentaux](/essentials).

Chaque étape correspond à un concept des signals Angular. Vous pouvez en faire une seule, ou toutes.

Si vous êtes bloqué, cliquez sur « Reveal answer » en haut de la page.

C'est parti, [commençons](/tutorials/signals/1-creating-your-first-signal) !
