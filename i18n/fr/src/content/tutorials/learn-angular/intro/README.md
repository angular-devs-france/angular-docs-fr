Ce tutoriel interactif vous enseigne les briques de base pour commencer à créer d'excellentes applications avec Angular.

## Comment utiliser ce tutoriel {#how-to-use-this-tutorial}

Vous aurez besoin de connaissances de base en HTML, CSS et JavaScript pour comprendre Angular.

Chaque étape représente un concept d'Angular. Vous pouvez en faire une seule, ou toutes.

Si vous êtes bloqué, cliquez sur « Reveal answer » en haut.

C'est parti, [commençons](/tutorials/learn-angular/1-components-in-angular).

## Utiliser l'IA pour le développement {#using-ai-for-development}

Si vous suivez ce tutoriel dans votre IDE préféré assisté par l'IA, [consultez les règles de prompt et les bonnes pratiques Angular](/ai/develop-with-ai).
