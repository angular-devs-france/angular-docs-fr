Ce tutoriel interactif vous apprend à créer des formulaires réactifs avec l'API Signal Forms d'Angular.

## Comment utiliser ce tutoriel {#how-to-use-this-tutorial}

Ce tutoriel suppose que vous maîtrisez les concepts de base d'Angular et que vous connaissez les bases des signals. Si vous découvrez Angular, lisez notre [guide des Fondamentaux](/essentials). Si vous découvrez les signals, suivez d'abord le [tutoriel sur les signals](/tutorials/signals).

Chaque étape présente un concept des Signal Forms. Vous allez créer un formulaire de connexion complet à partir de zéro, en apprenant les fondamentaux étape par étape.

**Votre parcours d'apprentissage :**

1. Mettre en place le model de formulaire avec TypeScript et les signals
2. Connecter le formulaire à votre template
3. Ajouter des règles de validation
4. Afficher les erreurs de validation aux utilisateurs
5. Gérer la soumission du formulaire
6. Explorer des sujets avancés et les prochaines étapes

Si vous êtes bloqué, cliquez sur « Reveal answer » en haut.

Allez, [c'est parti](/tutorials/signal-forms/1-set-up-form-model) !
