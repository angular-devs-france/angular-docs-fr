## Ce que vous avez appris {#what-you-learned}

Au fil de ce tutoriel, vous avez appris les fondamentaux des Signal Forms d'Angular :

1. **Models de formulaire** - Créer des données de formulaire typées avec les signals et la fonction `form()`
2. **Binding des champs** - Utiliser la directive `[formField]` pour le two-way binding des données et afficher le champ avec `value()`
3. **Validation** - Appliquer les validateurs intégrés (comme `required()`, `email()`) avec des messages personnalisés
4. **Affichage des erreurs** - Afficher les erreurs de validation de manière conditionnelle selon l'état du champ
5. **Soumission du formulaire** - Gérer la soumission du formulaire avec la fonction `submit()`
